# Phase 2: Homepage Simplification

A restructure, not a redesign — every removed section's content still exists in full at its own real page; nothing here is deleted from the site, only de-duplicated off the homepage. No visual system changes (same colors, type, buttons, spacing scale throughout).

## What changed, section by section

| Before | After | Why |
|---|---|---|
| No visible headline — page opened directly with the featured book; a screen-reader-only `<h1>` was the only top-level heading | New editorial hero: a real, visible `<h1>` ("Stories of suspense, love, faith and the choices that shape our lives."), one line of context, and three CTAs (Explore the Books / Start Here / Join the Reader Circle) | The brief's own request — still exactly one `<h1>` on the page, just a visible one now instead of hidden |
| `BookLaunchHero` showed a full milestone stat card, a bottom four-icon stat strip, bookstore-photo availability text, and the entire retailer-button row directly on the homepage | Trimmed to: cover(s), genre, title, one-line tagline, the book's real synopsis (already a genuine 40–60-word description — no new copy needed), "Explore the Book", "Read a Sample" (only if a real sample URL exists), and a "Choose Edition" label when a translation exists | All of that detail still renders in full on the book's own page (`BookDetail.tsx` + `BookHero.tsx` — confirmed `BookLaunchHero` was never used anywhere but the homepage, so nothing was lost by simplifying it) |
| No "Start Here" presence on the homepage at all (only reachable via nav) | A compact teaser: "Not sure where to begin?", the four real reading-mood categories as plain labels (not fake interactive filters — they don't exist as real anchors on `/start-here` yet, so they aren't linked individually), and one "Find Your Next Read" button to `/start-here` | Points to the real page rather than reproducing or pre-empting it |
| "The Bookshelf": every book in the catalog, with the full category-filter row, in a scrolling carousel | "Selected Books": the same four-book curated spread already used on `/about`'s "One World Per Book" (Shadow Code, Offbeat Love, A Journey of Grace, Vishnu Sahasranama), plus a "View All Books" button to `/books` | Removes the full-catalog duplication the brief specifically calls out; reuses an existing, already-approved curation instead of inventing a new one |
| (not present) | Short "About Gaurav" teaser — two sentences, one CTA to `/about` | Brief's explicit request; the full biography stays only at `/about` |
| The full three-benefit-card `WriteTogetherHub` component, shared with `/writing-resources` | A compact, homepage-only teaser (new inline markup — the shared component itself was left untouched since `/writing-resources` still needs the full version) | The detailed version still exists in full at `/write-together-hub` and `/writing-resources` |
| No closing section — the page just ended after the Reader Circle signup | New short "Find your next book." closer with two buttons (Browse All Books / Start Here) | Brief's explicit request |
| Testimonials carousel's duplicated clone slides were `aria-hidden` but not `inert` | Added `inert` to the clones, matching the fix already applied to `BookCarousel` during the Tailwind migration | Defense-in-depth — no focusable content exists inside a testimonial card today, so this wasn't a live bug the way `BookCarousel`'s was, but it closes the same gap if one's ever added |

Left unchanged, already compliant: `NewsPreview` and `BlogPreview` were already 3-item previews linking to their full archives (`/news`, `/blog`) — not the "full archive on the homepage" problem the brief describes. `Testimonials`' reviews are already real, traceable, admin-curated entries (audited in an earlier phase of this engagement). `PressStrip` renders nothing today because `pressQuotes` is a genuinely empty array (no fabricated quotes) — correct, honest behavior, not a bug.

## Verification

`npm run typecheck`, `npm run lint`, `npm run test`, the full `npm run test:e2e` (132 tests — including the two Phase 1 regression tests, which still pass unmodified against the new structure, confirming the header/hero consistency rule survived the redesign), the accessibility suite (28 routes including `/`, 0 violations), `npm run validate:content`, `npm run validate:links`, and `npm run build` all pass.

Manually verified live at both mobile (375px) and desktop (1280px) width: exactly one `<h1>` on the page; correct section order; the Selected Books grid renders 4 columns at desktop width and stacks cleanly on mobile; the Featured Book block's cover+text layout goes side-by-side on desktop and stacks on mobile; no horizontal overflow at either width; the header's "Explore Shadow Code" CTA still matches the hero's featured book exactly, through the real page text (not just the automated test). The main JS bundle for `/` shrank slightly (67.63KB vs ~73KB before), consistent with removing the category-filter/carousel logic from the eagerly-loaded homepage chunk.
